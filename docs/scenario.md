# 시나리오

## 절단산소 차단: P4_절단_중_오류

| 시간 | 기록 | JSON |
|---|---|---|
| 0~12.43초 직전 | 공급 표시 켜짐 | states[0] |
| 10초 | A형 오류음 | event_01 |
| 10.5~12초 | 불꽃·절단 홈 불안정 관찰 보고 | observation_01, observation_02 |
| 12.1초 | HIGH로 판단했다고 보고 | interpretation |
| 12.4초 | 절단산소 차단 버튼 누름 | event_02 |
| 12.43초 | 공급 표시 꺼짐 | states[1] |

P4는 시나리오 ID, DP5는 판단 지점 ID다. 작업 상태 S4는 시나리오에 따른 설정값이다.

Decision UPDATE는 10초 오류음, 12.1초 판단 보고, 12.4초 조작, 12.43초 화면 변화의 네 기록이다. 관측 구간은 12.1초 판단 기록의 근거 참조로 연결된다.

사후 기록용 예시다. 온라인 추론에 사용할 때는 selected_action_id 등 미래 사건을 참조하는 정보를 제외한다.

## 절단 유지: dp5-underreaction

| 시간 | 기준 위험도 | 예상 사용자 상태 | 대표 규칙 |
|---|---|---|---|
| 0초 | MID | Active Reasoning | R2 |
| 8초 | MID | Monitoring | R7 |
| 20초 | HIGH | Underreaction 가능성 | R5 |

합성 입력에 대한 예상값이다. 판단 원인은 과소평가와 위험 인지 후 미대응 두 가설로 남긴다.
