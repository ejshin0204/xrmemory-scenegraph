# 논의 사항

1. Geometry 좌표 단위, 원점, 축 방향과 rotation 표현.
2. 절단산소 차단 등 실제 BTN_*와 HTML 행동 분류의 대응. STOP으로 자동 매핑하지 않음.
3. HTML S0~S4 단계와 실제 촬영 절차의 단계 일치 여부.
4. 정상 버튼·전이 성공·기준 위험도 판정 기준과 평가자.
5. 시선·손 추적 방법과 데이터가 없을 때의 처리.
6. 여러 판단 보고를 저장할 interpretation 배열 확장 여부.
7. 사용자 상태 status의 전체 허용값. 현재 예시는 INSUFFICIENT_EVIDENCE만 사용.
8. 기록 보존 범위와 null 종료 시점의 관측 완료 기준.
